# Lisense plugins

Plugins that connect AI assistants to the [Lisense](https://lisense.uk) MCP server (`https://lisense.uk/mcp`) for UK vehicle data, MOT history and garage management. Each folder is a self-contained package.

| Folder | Platform |
| --- | --- |
| [`claude/`](claude/README.md) | Claude Code |
| `chatgpt/` | ChatGPT / Codex |

## Claude Code

```
/plugin marketplace add LisenseUK/lisense-plugins
/plugin install lisense@lisense
```

Then run `/mcp` and sign in with your Lisense account.

## ChatGPT

`chatgpt/` holds the package submitted to the OpenAI plugin directory.
