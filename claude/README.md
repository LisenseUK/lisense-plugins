# Lisense for Claude

Lisense connects Claude to UK vehicle data: DVLA details, tax status, recorded mileage, MOT history and advisories, partial registration search, enhanced specifications, Motability status, and your Lisense garage of vehicles, maintenance jobs and documents.

## Install

```
/plugin marketplace add LisenseUK/lisense-plugins
/plugin install lisense@lisense
```

Then run `/mcp`, select `plugin:lisense:lisense` and sign in with your Lisense account. Tools use your account's existing access, add-ons and search credits.

## Skills

- `/lisense:vehicle-check` summarises a UK registration's tax, MOT history, mileage and advisories.
- `/lisense:log-service` turns invoices or receipts into reviewed maintenance jobs in your garage.
